Git Commands Reference

Compiled from session — 9 May 2026

⚠️ Token Security: Never hardcode tokens in URLs or commit them. Use git remote set-url with a token only temporarily, then rotate the token afterward. Prefer SSH keys or credential helpers for persistent auth.

Clone & Config

$ git clone https://github.com/bighead12/UFence.git
Download the repo to your local machine.
$ git config user.name "agent6605"
$ git config user.email "agent6605@users.noreply.github.com"
Set local identity for commits (omit --global to scope to current repo only).

Status & Inspection

$ git status
Show modified, staged, and untracked files.
$ git diff
Show unstaged changes line-by-line.
$ git log --oneline -5
Show last 5 commits in compact format.
$ git remote -v
List remote URLs (fetch & push).

Branch & Commit

$ git checkout -b feature/chat-interface
Create and switch to a new feature branch.
$ git add app.py config/fencing_rules.json src/crew/fencing_crew.py src/visualization/animator.py
Stage specific files for commit (exclude streamlit.log and other artifacts).
$ git commit -m "Replace dropdown UI with chat-based interface using LLM intent interpretation"
Commit staged changes with a descriptive message.

Remote & Push

$ git remote set-url origin https://github.com/agent6605:TOKEN@github.com/bighead12/UFence.git
Temporarily embed a token in the remote URL for authenticated push.
$ git push -u origin feature/chat-interface
Push local branch to remote and set upstream tracking (-u).
$ git remote set-url origin https://github.com/bighead12/UFence.git
Remove token from remote URL after push completes.

Quick Reference

Command What it does
git clone <url> Download a repo
git checkout -b <branch> Create & switch to new branch
git add <file> Stage changes for commit
git commit -m "msg" Commit staged changes
git push -u origin <branch> Push branch to remote (first time)
git push Push commits (upstream set)
git remote -v Show remote URLs
git remote set-url origin <url> Change remote URL
git status Check working tree state
git diff View unstaged changes
git log --oneline -N Show last N commits (one line each)
